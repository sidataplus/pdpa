# คู่มือแก้ไขเว็บ PDPA (แต่ละมาตรา)

เว็บนี้เก็บเนื้อหากฎหมาย PDPA ทุกมาตราเป็นไฟล์ Markdown แยกกันอยู่ใน `content/` ถ้ามาตราไหนมีประกาศ/กฎหมายลูกที่เกี่ยวข้อง จะมีไฟล์แยกเพิ่มใน `content/highlights/` ด้วย

เวลาจะเพิ่มหรือแก้ไขมาตรา ให้ดูหัวข้อที่เกี่ยวข้องด้านล่าง

---

## เพิ่มมาตราใหม่

### ขั้นที่ 1 สร้างไฟล์เนื้อหา

สร้างไฟล์ใหม่ที่ `content/article-[เลข].md` โดยขึ้นต้นด้วย frontmatter แบบนี้เสมอ:

```yaml
---
title: มาตรา ๓๗
aliases: ['มาตรา 37', 'ม37', 'ม 37']
---
```

**ข้อควรระวังเรื่อง aliases:**
ต้องใช้เลขอารบิก (37) ไม่ใช่เลขไทย (๓๗) เพราะระบบสร้าง slug จะตัดตัวอักษรไทยออก ทำให้ `ม๓๗` กับ `ม37` กลายเป็นคนละ key ถ้าใส่ผิดจะ link ไม่เจอกัน

ค่า aliases ที่ใส่ไว้ต้องตรงกับ key ที่จะใส่ใน `toc-structure.js` ด้วย เช่น ถ้า toc ใส่ `'ม37'` ก็ต้องมี `'ม37'` อยู่ใน aliases

### ขั้นที่ 2 ใส่มาตราใน `lib/toc-structure.js`

เปิดไฟล์ `lib/toc-structure.js` แล้วหาหมวดที่ถูกต้อง จากนั้นเพิ่ม `'ม[เลข]'` เข้าไปใน array `articles` ของหมวดนั้น

ถ้าข้ามขั้นนี้ไป มาตราจะไม่ขึ้นใน sidebar เลย แม้จะสร้างไฟล์ไปแล้วก็ตาม

### ขั้นที่ 3 สร้างไฟล์ Highlight (ถ้ามีประกาศลูก)

ถ้ามาตรานั้นมีประกาศคณะกรรมการหรือกฎหมายลูกเพิ่มเติม ให้สร้างไฟล์ที่ `content/highlights/highlight-article-[เลข]-[ย่อย].md`

frontmatter ของไฟล์ Highlight:
```yaml
---
slug: "highlight-article-37-1"
title: "ชื่อประกาศเต็มๆ..."
pdf: "/pdfs/article-37-1.pdf"
main_pdf_link: "https://www.pdpc.or.th/..."
---
```

**สำคัญมาก — `main_pdf_link` ห้ามเว้นว่างเด็ดขาด:**
ฟิลด์นี้คือลิงก์ PDF ต้นฉบับจากเว็บไซต์ PDPC ที่จะแสดงในกล่องด้านล่างของหน้า Highlight ให้ผู้ใช้คลิกดาวน์โหลดได้ ถ้าเว้นว่างไว้ กล่องลิงก์ PDF จะหายไปจากหน้าเว็บ ทำให้ผู้ใช้หาเอกสารต้นฉบับไม่ได้ ให้ดูลิงก์จากคอลัมน์ใน Excel หรือเปิดหน้าเว็บ PDPC เพื่อหา URL ของ PDF มาใส่ให้ครบเสมอ

---

## แก้ไขมาตราที่มีอยู่แล้ว

เปิดไฟล์ที่ถูกต้องแล้วแก้ได้เลย:
- มาตราหลัก อยู่ที่ `content/article-[เลข].md`
- ประกาศ/กฎหมายลูก อยู่ที่ `content/highlights/highlight-article-[เลข]-[ย่อย].md`

ไม่ต้องแตะ `toc-structure.js` ถ้าแค่แก้เนื้อหา

---

## กฎการเขียนเนื้อหา

### การจัดย่อหน้า
- **ไฟล์มาตราหลัก (`article-*.md`)** — ต้องนำหน้าทุกย่อหน้าด้วย `&emsp; ` (มี space ต่อท้ายด้วย) เพราะไฟล์นี้ผ่าน Markdown renderer ที่แปลง HTML entity ได้
- **ไฟล์ Highlight (`highlight-*.md`)** — ต้องใช้ **4 spaces** นำหน้าแทน เพราะ Highlight แสดงผลเป็น plain text โดยตรง ถ้าใส่ `&emsp;` จะโชว์เป็นตัวหนังสือดิบๆ ไม่ใช่ช่องว่าง

### ตัวเลขและหัวข้อย่อย
ในเนื้อหาให้ใช้เลขไทยและอักษรไทยเสมอ:
- หัวข้อหลัก → `(๑)` `(๒)` `(๓)`
- หัวข้อย่อย → `(ก)` `(ข)` `(ค)`

### ลิงก์ภายใน
- **อ้างถึงมาตราอื่น** → ครอบด้วย `[[ ]]` เช่น `[[มาตรา ๒๘]]`
- **ลิงก์ไปหน้า Highlight** → **ห้ามเขียนแยกบรรทัด "ดูเพิ่มเติม" ไว้ท้ายมาตราเด็ดขาด** ให้ใช้ Markdown link ครอบคำในประโยคที่อ้างถึงประกาศนั้นๆ โดยตรง เช่น คำว่า `[คณะกรรมการประกาศกำหนด](/highlight-article-40-3)` หรือ `[พระราชกฤษฎีกา](/highlight-article-4)` ที่ปรากฏในเนื้อหา
  - **การเลือกคำที่จะ highlight (สำคัญ):** คำที่ครอบลิงก์ต้องเป็น **คำที่ระบุถึงประกาศนั้นๆ โดยตรงและเฉพาะเจาะจงที่สุด** ในประโยค เช่น ถ้าประโยคพูดถึงการที่ "คณะกรรมการประกาศกำหนด" ให้ครอบที่คำนี้ ห้ามครอบที่คำทั่วไปอย่าง "ตามที่กำหนด" หรือ "ตามหลักเกณฑ์" เพราะจะทำให้ผู้อ่านไม่รู้ว่าลิงก์นั้นพาไปที่ไหน
  - **สำคัญมาก:** ห้ามเดาชื่อลิงก์ (slug) หรือเดาชื่อประกาศเอาเอง ให้เปิดอ่านไฟล์ **`data/โยงประกาศ PDPA.xlsx`** เป็นหลัก
  - **ทุกครั้งเมื่อทำการเชื่อมเนื้อหา** ดูคอลัมน์ `มาตรา` และ `เอกสารเชื่อมโยง` เพื่อจับคู่ว่าคำในมาตรานี้ ต้องโยงไปที่ไฟล์ประกาศชื่ออะไร
  - **กรณีมีประกาศใหม่ (เมื่อเพิ่มมาตราใหม่):** หากมีการสั่งงานว่า "เพิ่มประกาศ/มาตราใหม่ใน Excel แล้ว" ให้เริ่มต้นด้วยการ **อ่านไฟล์ `data/โยงประกาศ PDPA.xlsx` เพื่ออัปเดตข้อมูลและดึงเนื้อหามาตราล่าสุดก่อนเสมอ** จากนั้นจึงสร้างไฟล์ markdown (`highlight-article-*.md`), จัดหน้าตามกฎ, และโยงลิงก์ให้สมบูรณ์

### ห้ามสรุปเนื้อหาเด็ดขาด
- **ห้ามสรุปเนื้อหาเด็ดขาด:** ต้องคัดลอกข้อความกฎหมายหรือประกาศมาแบบเป๊ะๆ ตามต้นฉบับที่ให้มา ห้ามตัดหรือย่อความเองเด็ดขาด (เช่น ถ้าระบุว่ามี (๑) ถึง (๖) พร้อมรายละเอียด ก็ต้องใส่รายละเอียดให้ครบถ้วนทุกประโยค)
